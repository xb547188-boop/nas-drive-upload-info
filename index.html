NAS Google Drive Upload

A private, owner-operated upload task that copies a configured folder from a Synology NAS to the owner's selected Google Drive folder.

How it works

The task runs on the NAS using rclone. It checks for new or updated files on a daily schedule and uploads them to the configured destination. The source is mounted read-only. The configured copy task does not delete cloud files when source files are removed.

Account access

The owner authorizes Google Drive access through Google OAuth. The Drive permission requested by rclone allows access to all Drive files; the task's configuration limits its operations to the selected destination folder. This is a configuration boundary, not a Google-enforced folder-only permission.

This page provides application information only. It does not accept logins, upload files, or provide access to the owner's NAS or Drive.
